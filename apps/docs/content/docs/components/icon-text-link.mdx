## 기본 예시

`leftIcon`·`rightIcon`에 아이콘 이름(lucide)을 넘기면 텍스트 좌/우에 표시됩니다. 사용 가능한 이름은 [Lucide 아이콘 목록](https://lucide.dev/icons/)에서 확인하세요.

<Preview>
  <IconTextLink leftIcon="link" href="#">왼쪽 아이콘</IconTextLink>
  <IconTextLink rightIcon="external-link" href="#">오른쪽 아이콘</IconTextLink>
</Preview>

```tsx
import { IconTextLink } from '@bigmobility/vinyl-ui/link';

export default function IconTextLinkExample() {
  return (
    <>
      <IconTextLink
        leftIcon="link"
        href="#"
      >
        왼쪽 아이콘
      </IconTextLink>
      <IconTextLink
        rightIcon="external-link"
        href="#"
      >
        오른쪽 아이콘
      </IconTextLink>
    </>
  );
}
```

## 라우팅 라이브러리

`asChild`를 사용하면 IconTextLink가 자체 `<a>` 요소 대신 자식 라우팅 컴포넌트를 렌더하며, 스타일과 속성이 자식에 병합됩니다. 이를 통해 전체 페이지 리로드 없이 클라이언트 사이드 라우팅을 적용할 수 있습니다. 내부 아이콘은 자식 요소 안에 자동으로 주입됩니다.

<Preview>
  <IconTextLink asChild leftIcon="link"><Link href="/">링크 텍스트</Link></IconTextLink>
</Preview>

```tsx
import Link from 'next/link';
import { IconTextLink } from '@bigmobility/vinyl-ui/link';

export default function AsChildIconTextLink() {
  return (
    <IconTextLink
      asChild
      leftIcon="link"
    >
      <Link href="/">링크 텍스트</Link>
    </IconTextLink>
  );
}
```

### Next.js 바인딩

Next.js 프로젝트에서는 `@bigmobility/vinyl-ui/link/next`를 사용하면 `asChild`를 직접 쓰지 않아도 됩니다. 내부적으로 `next/link`를 사용하여 클라이언트 사이드 라우팅을 지원합니다. Next.js 14 이상이 필요합니다.

```tsx
import { IconTextLink } from '@bigmobility/vinyl-ui/link/next';

export default function NextIconTextLinkExample() {
  return (
    <IconTextLink
      leftIcon="link"
      href="/dashboard"
    >
      대시보드
    </IconTextLink>
  );
}
```

## 접근성

- 네이티브 `<a>` 요소를 사용하므로 **키보드 포커스·Enter 활성화**가 기본 동작합니다.
- `<a>` 요소는 네이티브 `disabled` 속성을 지원하지 않으므로, `disabled`를 전달하면 `aria-disabled="true"`로 보조 기기에 비활성 상태를 전달하고 `tabIndex={-1}`로 키보드 포커스 순서에서 제외합니다.
- 새 창/탭으로 열리는 링크(`target="_blank"`)에는 `aria-label`을 추가하여 화면 낭독기 사용자에게 고지하세요.
- `href` 없이 클릭 동작만 필요한 경우에는 이 컴포넌트 대신 `Button`을 사용하세요.

## 토큰 커스터마이징

IconTextLink는 아래 시맨틱 토큰을 참조합니다. ([테마](/docs/theming) 참고).

| 토큰 | 미리보기 | 용도 |
| --- | --- | --- |
| `text.default` | <Swatch token="text.default" /> | 기본 텍스트·아이콘 색상 |
| `text.accent-primary` | <Swatch token="text.accent-primary" /> | hover·active 텍스트·아이콘 색상 |
| `text.disable` | <Swatch token="text.disable" /> | 비활성 텍스트·아이콘 색상 |

타이포는 `body.medium-normal` textStyle을 사용합니다.
