## 개요

`TextField`는 라벨·입력·에러 메시지를 사용하기 쉽게 완성된 형태로 제공되는 컴포넌트입니다.

## 기본 예시

<Preview>
  <TextFieldDemo
    name="email"
    label="이메일"
    placeholder="you@example.com"
    required
  />
</Preview>

```tsx
import { useState } from 'react';

import { TextField } from '@bigmobility/vinyl-ui/field';

export default function TextFieldExample() {
  const [field, setField] = useState({
    email: '',
    error: '',
  });

  const handleChange = ({ name, value }: {
    name: string;
    value: string;
  }) => {
    setField({
      ...field,
      [name]: value,
    });
  }

  return (
    <TextField
      name="email"
      label="이메일"
      value={field.email}
      placeholder="you@example.com"
      required
      errorMessage={field.error}
      onChangeField={handleChange}
    />
  );
}
```

## 에러

`errorMessage`를 전달하면 에러 상태가 되어 입력 스타일이 바뀌고 메시지가 노출됩니다.

<Preview>
  <TextFieldDemo
    name="email"
    label="이메일"
    errorMessage="올바른 이메일 형식이 아닙니다"
  />
</Preview>

```tsx
<TextField
  name="email"
  label="이메일"
  value={email}
  errorMessage={error}
  onChangeField={({ value }) => setEmail(value)}
/>
```
